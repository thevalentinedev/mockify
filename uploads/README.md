# PDF Uploads

Drop exam PDFs into the matching school/subject folder:

```
uploads/
  conestoga/
    english/     ← English exam PDFs
    maths/       ← Mathematics exam PDFs
    biology/     ← Biology exam PDFs
    chemistry/   ← Chemistry exam PDFs
```

You can also upload via the **Import PDFs** page in the app.

After extraction, question banks are saved to `data/banks/{school}/{subject}.json`.
